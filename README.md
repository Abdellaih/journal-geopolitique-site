# Journal géopolitique

Actualités géopolitiques expliquées et leur impact sur le Maroc, en français et en anglais.
Geopolitics news explained, with what it means for Morocco, in French and English.

- `index.html`: page d'accueil / home page
- `journal/`: le journal (les entrées sont dans `journal/entries.json`) / the logbook (entries live in `journal/entries.json`)
- `hormuz/`: dossier interactif « From Hormuz to the Pump » (en anglais) / interactive explainer (English)

Site statique publié avec GitHub Pages. Static site published with GitHub Pages.
